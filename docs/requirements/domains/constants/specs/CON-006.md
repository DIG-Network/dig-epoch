## Summary

Sentinel constants provide well-known values used as defaults and boundary markers throughout the crate. `EMPTY_ROOT` is the SHA-256 hash of the empty string, used as the default Merkle root for empty collections and as the initial DFSP root in `EpochInfo::new()`.

## Specification

```rust
/// SHA-256 hash of the empty string.
/// Used as the default root for empty Merkle trees (VER-001, VER-003)
/// and as the initial value for DFSP roots in EpochInfo::new().
pub const EMPTY_ROOT: Bytes32 = Bytes32::new([
    0xe3, 0xb0, 0xc4, 0x42, 0x98, 0xfc, 0x1c, 0x14,
    0x9a, 0xfb, 0xf4, 0xc8, 0x99, 0x6f, 0xb9, 0x24,
    0x27, 0xae, 0x41, 0xe4, 0x64, 0x9b, 0x93, 0x4c,
    0xa4, 0x95, 0x99, 0x1b, 0x78, 0x52, 0xb8, 0x55,
]);
```

## Acceptance Criteria

- `EMPTY_ROOT` is `Bytes32` and equals SHA-256 of the empty string
- `EMPTY_ROOT` is `pub const` and accessible from the crate root
- `EMPTY_ROOT` matches the canonical value `e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`

## Implementation Notes

- `EMPTY_ROOT` is used by `compute_epoch_block_root()` (VER-001) and `compute_epoch_withdrawals_root()` (VER-003) as the return value for empty input slices
- `EpochInfo::new()` initializes all four DFSP roots (`collateral_registry_root`, `cid_state_root`, `node_registry_root`, `namespace_epoch_root`) to `EMPTY_ROOT`
- The value is the well-known SHA-256 of `b""` and should be verified against a runtime SHA-256 computation in tests
