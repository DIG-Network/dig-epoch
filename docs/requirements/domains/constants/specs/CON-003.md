# CON-003: Reward Economics Constants

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)
> **Verification:** [VERIFICATION.md](../VERIFICATION.md)
> **Tracking:** [TRACKING.yaml](../TRACKING.yaml)

## Summary

Reward economics constants define the emission schedule, halving parameters, and per-epoch reward values for the DIG L2 blockchain. These are economic commitments that MUST be identical across all validators and MUST NOT be runtime-configurable.

## Specification

```rust
/// 1 L2 token = 10^12 mojos.
pub const MOJOS_PER_L2: u64 = 1_000_000_000_000;

/// L2 block time in milliseconds.
pub const L2_BLOCK_TIME_MS: u64 = 3_000;

/// L2 blocks per 10-minute window.
pub const L2_BLOCKS_PER_10_MIN: u64 = 200; // 600_000 / 3_000

/// Initial emission rate: 64 L2 per 10 minutes.
pub const INITIAL_EMISSION_PER_10_MIN: u64 = 64 * MOJOS_PER_L2;

/// Tail emission rate: 4 L2 per 10 minutes.
pub const TAIL_EMISSION_PER_10_MIN: u64 = 4 * MOJOS_PER_L2;

/// Per-block reward before any halving (0.32 L2).
/// Derived: INITIAL_EMISSION_PER_10_MIN / L2_BLOCKS_PER_10_MIN.
pub const INITIAL_BLOCK_REWARD: u64 = 320_000_000_000;

/// Per-block reward at tail emission (0.02 L2).
/// Derived: TAIL_EMISSION_PER_10_MIN / L2_BLOCKS_PER_10_MIN.
pub const TAIL_BLOCK_REWARD: u64 = 20_000_000_000;

/// Halving interval: ~3 years of blocks at 3s block time.
pub const HALVING_INTERVAL_BLOCKS: u64 = 94_608_000;

/// Number of halvings before switching to tail emission.
pub const HALVINGS_BEFORE_TAIL: u64 = 4;

/// Initial epoch reward (sum of block rewards across one epoch).
/// 32 * INITIAL_BLOCK_REWARD = 10.24 L2.
pub const INITIAL_EPOCH_REWARD: u64 = 32_000_000_000_000;

/// Halving interval in epochs.
pub const HALVING_INTERVAL_EPOCHS: u64 = 315_576;

/// Minimum epoch reward (tail emission floor).
pub const MINIMUM_EPOCH_REWARD: u64 = 2_000_000_000_000;

/// Bonus reward for the first block after an epoch checkpoint.
pub const EPOCH_FIRST_BLOCK_BONUS: u64 = 100_000_000_000;
```

**Derivations and relationships:**

| Relationship | Expression |
|-------------|-----------|
| INITIAL_BLOCK_REWARD | `INITIAL_EMISSION_PER_10_MIN / L2_BLOCKS_PER_10_MIN` = `64_000_000_000_000 / 200` = `320_000_000_000` |
| TAIL_BLOCK_REWARD | `TAIL_EMISSION_PER_10_MIN / L2_BLOCKS_PER_10_MIN` = `4_000_000_000_000 / 200` = `20_000_000_000` |
| INITIAL_EPOCH_REWARD | `BLOCKS_PER_EPOCH * INITIAL_BLOCK_REWARD` = `32 * 320_000_000_000` = `10_240_000_000_000` |
| HALVING_INTERVAL_EPOCHS | `HALVING_INTERVAL_BLOCKS / BLOCKS_PER_EPOCH` = `94_608_000 / 32` = `2_956_500` |

## Acceptance Criteria

- `MOJOS_PER_L2` is `u64` and equals `1_000_000_000_000`
- `L2_BLOCK_TIME_MS` is `u64` and equals `3_000`
- `L2_BLOCKS_PER_10_MIN` is `u64` and equals `200`
- `INITIAL_EMISSION_PER_10_MIN` is `u64` and equals `64 * MOJOS_PER_L2`
- `TAIL_EMISSION_PER_10_MIN` is `u64` and equals `4 * MOJOS_PER_L2`
- `INITIAL_BLOCK_REWARD` is `u64` and equals `320_000_000_000`
- `TAIL_BLOCK_REWARD` is `u64` and equals `20_000_000_000`
- `HALVING_INTERVAL_BLOCKS` is `u64` and equals `94_608_000`
- `HALVINGS_BEFORE_TAIL` is `u64` and equals `4`
- `INITIAL_EPOCH_REWARD` is `u64` and equals `32_000_000_000_000`
- `HALVING_INTERVAL_EPOCHS` is `u64` and equals `315_576`
- `MINIMUM_EPOCH_REWARD` is `u64` and equals `2_000_000_000_000`
- `EPOCH_FIRST_BLOCK_BONUS` is `u64` and equals `100_000_000_000`
- `TAIL_BLOCK_REWARD < INITIAL_BLOCK_REWARD`
- All constants are `pub const` and accessible from the crate root

## Implementation Notes

- `HALVINGS_BEFORE_TAIL` is `u64` (not `u32`) to match the type used in halving arithmetic with u64 block heights
- The 4 intermediate emission constants (`L2_BLOCK_TIME_MS`, `L2_BLOCKS_PER_10_MIN`, `INITIAL_EMISSION_PER_10_MIN`, `TAIL_EMISSION_PER_10_MIN`) document the derivation chain from emission rates to per-block rewards
- These constants are economic commitments and MUST NOT be runtime-configurable
