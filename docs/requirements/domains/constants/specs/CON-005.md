# CON-005: DFSP, Consensus, Slashing Constants

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)
> **Verification:** [VERIFICATION.md](../VERIFICATION.md)
> **Tracking:** [TRACKING.yaml](../TRACKING.yaml)
> **Spec reference:** [SPEC.md - Sections 2.4, 2.5, 2.6](../../../../resources/SPEC.md)

## Summary

DFSP, consensus, slashing, and withdrawal constants govern the DFSP subsystem parameters, consensus thresholds for checkpoint finality, and slashing/withdrawal timing. These constants are protocol commitments that MUST be identical across all validators.

## Specification

**DFSP epoch parameters:**

```rust
/// Wall-clock seconds per DFSP accounting epoch.
/// Derived: (32 blocks * 3000ms) / 1000.
pub const DFSP_WALL_CLOCK_EPOCH_SECONDS: u64 = 96;

/// Network epochs a CID may remain in Grace state before expiring.
/// Derived from 30-day grace window: (30 * 24 * 3600) / 96.
pub const DFSP_GRACE_PERIOD_NETWORK_EPOCHS: u64 = 27_000;

/// Bootstrap genesis issuance subsidy per evaluated epoch (mojos).
pub const DFSP_GENESIS_ISSUANCE_SUBSIDY_MOJOS_V1: u128 = 0;

/// DFSP activation height (default: disabled).
pub const DFSP_ACTIVATION_HEIGHT: u64 = u64::MAX;

/// Environment variable name for DFSP activation height override.
pub const DIG_DFSP_ACTIVATION_HEIGHT_ENV: &str = "DIG_DFSP_ACTIVATION_HEIGHT";
```

**Consensus thresholds:**

```rust
/// Stake percentage required for soft finality.
pub const SOFT_FINALITY_THRESHOLD_PCT: u64 = 67;

/// Stake percentage required for a checkpoint to win the competition.
pub const HARD_FINALITY_THRESHOLD_PCT: u64 = 67;

/// Stake percentage required for a valid checkpoint submission.
pub const CHECKPOINT_THRESHOLD_PCT: u64 = 67;
```

**Slashing and withdrawal:**

```rust
/// Epochs to track for correlation penalty calculation.
pub const CORRELATION_WINDOW_EPOCHS: u32 = 36;

/// Maximum lookback for slashable offenses (in epochs).
pub const SLASH_LOOKBACK_EPOCHS: u64 = 1_000;

/// DFSP slashing evidence lookback (same as general slashing).
pub const DFSP_SLASH_LOOKBACK_EPOCHS: u64 = SLASH_LOOKBACK_EPOCHS;

/// Epochs before a withdrawal completes.
pub const WITHDRAWAL_DELAY_EPOCHS: u64 = 50;
```

## Acceptance Criteria

- `DFSP_WALL_CLOCK_EPOCH_SECONDS` is `u64` and equals `96`
- `DFSP_GRACE_PERIOD_NETWORK_EPOCHS` is `u64` and equals `27_000`
- `DFSP_GENESIS_ISSUANCE_SUBSIDY_MOJOS_V1` is `u128` and equals `0`
- `DFSP_ACTIVATION_HEIGHT` is `u64` and equals `u64::MAX`
- `DIG_DFSP_ACTIVATION_HEIGHT_ENV` is `&str` and equals `"DIG_DFSP_ACTIVATION_HEIGHT"`
- `SOFT_FINALITY_THRESHOLD_PCT` is `u64` and equals `67`
- `HARD_FINALITY_THRESHOLD_PCT` is `u64` and equals `67`
- `CHECKPOINT_THRESHOLD_PCT` is `u64` and equals `67`
- `CORRELATION_WINDOW_EPOCHS` is `u32` and equals `36`
- `SLASH_LOOKBACK_EPOCHS` is `u64` and equals `1_000`
- `DFSP_SLASH_LOOKBACK_EPOCHS` is `u64` and equals `SLASH_LOOKBACK_EPOCHS`
- `WITHDRAWAL_DELAY_EPOCHS` is `u64` and equals `50`
- All constants are `pub const` and accessible from the crate root

## Implementation Notes

- `CORRELATION_WINDOW_EPOCHS` is `u32` (not `u64`) per SPEC Section 2.6
- `DFSP_GENESIS_ISSUANCE_SUBSIDY_MOJOS_V1` is `u128` to match the mojo precision used in DFSP issuance calculations
- `DIG_DFSP_ACTIVATION_HEIGHT_ENV` provides the environment variable name used by `dfsp_activation_height_for_network()` (DFS-005) to override the default activation height
- `DFSP_SLASH_LOOKBACK_EPOCHS` is an alias for `SLASH_LOOKBACK_EPOCHS`, ensuring DFSP slashing uses the same lookback window as general slashing
- DFSP derivations: `DFSP_WALL_CLOCK_EPOCH_SECONDS == (BLOCKS_PER_EPOCH * L2_BLOCK_TIME_MS) / 1000`
