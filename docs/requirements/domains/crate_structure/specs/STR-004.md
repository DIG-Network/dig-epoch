# STR-004: EpochManager Constructor

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)

## Summary

The `EpochManager::new()` constructor creates a manager at epoch 0 with deterministic initial state derived from three parameters: network identity, the L1 genesis anchor, and the initial CoinSet state root. The constructor establishes the invariant that the manager always has a valid current epoch with correct phase and empty competition/reward maps.

## Specification

```rust
impl EpochManager {
    pub fn new(
        network_id: Bytes32,
        genesis_l1_height: u32,
        initial_state_root: Bytes32,
    ) -> Self {
        Self {
            current_epoch: RwLock::new(EpochInfo::new(
                0,                    // epoch number
                genesis_l1_height,    // start L1 height
                GENESIS_HEIGHT,       // start L2 height (always 1)
                initial_state_root,   // CoinSet state root at genesis
            )),
            history: RwLock::new(HashMap::new()),
            competitions: RwLock::new(HashMap::new()),
            rewards: RwLock::new(HashMap::new()),
            network_id,
            genesis_l1_height,
        }
    }
}
```

| Property | Expected Value |

| `current_phase()` | `EpochPhase::BlockProduction` |
| `current_epoch_info().epoch` | `0` |
| `current_epoch_info().start_l1_height` | `genesis_l1_height` |
| `current_epoch_info().end_l1_height` | `genesis_l1_height + EPOCH_L1_BLOCKS` |

| `current_epoch_info().start_state_root` | `initial_state_root` |

| `get_rewards(0)` | `None` |

## Acceptance Criteria

- Constructor accepts exactly three parameters: `network_id`, `genesis_l1_height`, `initial_state_root`
- Returns an `EpochManager` at epoch 0 in `BlockProduction` phase
- All mutable counters (blocks_produced, total_fees, total_transactions) are zero
- History, competitions, and rewards maps are empty
- `network_id` and `genesis_l1_height` are stored and accessible via getter methods
- `EpochInfo` start state root matches the provided `initial_state_root`
- DFSP close snapshot fields default to `EMPTY_ROOT` / `0`

## Implementation Notes

- `RwLock` is from `parking_lot`, not `std::sync`, for performance and no poisoning
- `GENESIS_HEIGHT` is the constant `1` from `constants.rs`
- `EpochInfo::new()` handles setting `end_l1_height = start_l1_height + EPOCH_L1_BLOCKS` and defaulting DFSP roots to `EMPTY_ROOT`
- `network_id` and `genesis_l1_height` are immutable after construction (no `RwLock` needed)
- The constructor does not start a checkpoint competition; that happens explicitly via `start_checkpoint_competition()`
