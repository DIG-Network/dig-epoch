# STR-003: Public Re-exports

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)
> **Verification:** [VERIFICATION.md](../VERIFICATION.md)
> **Tracking:** [TRACKING.yaml](../TRACKING.yaml)
> **Spec reference:** [SPEC.md - Section 12](../../../../resources/SPEC.md)

## Summary

The crate's `lib.rs` must re-export the entire public API surface so that consumers can access all items via `use dig_epoch::*` without navigating internal module structure. This flat re-export pattern is consistent with the two-audience design: both stateless function users and stateful EpochManager users import from the same crate root.

## Specification

`lib.rs` MUST re-export the following items:

**Manager:**
```rust
pub use manager::EpochManager;
```

**Types (structs and enums):**
```rust
pub use types::{
    EpochPhase, PhaseTransition,
    EpochInfo, EpochSummary,
    DfspCloseSnapshot, DfspExecutionStageV1,
    DfspEpochBurnContextV1, DfspEpochBurnPolicyV1,
    DfspEpochBurnPolicyScheduleEntryV1,
    DfspEpochStorageProofEvaluationContextV1,
    DfspEpochIssuancePreviewV1,
    EpochEvent, EpochStats,
    CheckpointCompetition, CompetitionStatus,
    RewardDistribution,
    EpochCheckpointData, EpochBlockLink,
};
```

**Constants:**
```rust
pub use constants::*;
```

**Free functions:**

## Acceptance Criteria

- `use dig_epoch::EpochManager` compiles successfully
- `use dig_epoch::EpochPhase` and all other type names compile successfully
- `use dig_epoch::BLOCKS_PER_EPOCH` and all other constant names compile successfully
- `use dig_epoch::epoch_for_block_height` and all other free function names compile successfully
- `use dig_epoch::EpochError` and `use dig_epoch::CheckpointCompetitionError` compile successfully
- `use dig_epoch::*` brings all public items into scope without ambiguity

## Implementation Notes

- The `pub use` statements in `lib.rs` should be grouped by category (manager, types, constants, functions, errors) with comments for readability
- Internal module declarations (`mod constants;`, `mod types;`, etc.) should not be `pub` themselves; only the re-exported items are public
- If any internal type is accidentally not re-exported, downstream consumers will get a "type is private" error at compile time
