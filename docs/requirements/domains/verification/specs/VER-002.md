# VER-002: Block Inclusion Proof

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)
> **Verification:** [VERIFICATION.md](../VERIFICATION.md)
> **Tracking:** [TRACKING.yaml](../TRACKING.yaml)
> **Spec reference:** [SPEC.md - Section 7.2](../../../../resources/SPEC.md)

## Summary

epoch_block_inclusion_proof generates a Merkle proof that a specific block (identified by index) is included in the epoch's block list. This enables lightweight verification of block membership without transmitting the entire block hash list.

## Specification

epoch_block_inclusion_proof MUST be implemented as follows:

```rust
pub fn epoch_block_inclusion_proof(
    block_hashes: &[Bytes32],
    index: usize,
) -> Option<MerkleProof> {
    if index >= block_hashes.len() {
        return None;
    }

    let tree = MerkleTree::new(block_hashes);
    Some(tree.proof(index))
}
```

Key rules:
- MUST return None if index >= block_hashes.len() (out of bounds)
- MUST use chia-sdk-types::MerkleTree to build the tree and generate the proof
- The returned MerkleProof MUST be verifiable against the epoch block root (VER-001)
- The proof MUST confirm that block_hashes[index] is a leaf at position `index` in the Merkle tree

## Acceptance Criteria

- [ ] Returns None for out-of-bounds index
- [ ] Returns None for empty block_hashes with any index
- [ ] Returns Some(MerkleProof) for valid index
- [ ] Proof is verifiable against compute_epoch_block_root(block_hashes)
- [ ] Proof works for index 0 (first block)
- [ ] Proof works for last index (last block)
- [ ] Proof works for middle index

## Implementation Notes

- MerkleProof is a type from chia-sdk-types that contains the sibling hashes needed to reconstruct the root
- Proof verification is done by hashing the leaf with its siblings up to the root and comparing against the known root
- This function is used by light clients and validators to verify block inclusion without full block lists
- The proof size is O(log n) where n is the number of blocks in the epoch
