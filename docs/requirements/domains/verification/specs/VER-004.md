# VER-004: Checkpoint Data and Sign Material

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)
> **Verification:** [VERIFICATION.md](../VERIFICATION.md)
> **Tracking:** [TRACKING.yaml](../TRACKING.yaml)
> **Spec reference:** [SPEC.md - Sections 7.4, 7.5](../../../../resources/SPEC.md)

## Summary

EpochCheckpointData encapsulates the core data needed for an epoch checkpoint. EpochCheckpointSignMaterial extends this with the score and signing digest, providing everything validators need to produce their BLS signature contribution. The epoch_checkpoint_sign_material_from_l2_blocks() function constructs sign material directly from L2 block data.

## Specification

EpochCheckpointData MUST contain:

```rust
pub struct EpochCheckpointData {
    pub network_id: Bytes32,
    pub epoch: u64,
    pub block_root: Bytes32,
    pub state_root: Bytes32,
    pub withdrawals_root: Bytes32,
    pub checkpoint_hash: Bytes32,
}
```

EpochCheckpointSignMaterial MUST contain:

```rust
pub struct EpochCheckpointSignMaterial {
    pub checkpoint: EpochCheckpointData,
    pub score: u64,
    pub signing_digest: Bytes32,
}
```

epoch_checkpoint_sign_material_from_l2_blocks() MUST:
- Compute block_root from block hashes via compute_epoch_block_root (VER-001)
- Extract state_root from the final block's state
- Compute withdrawals_root from withdrawal hashes via compute_epoch_withdrawals_root (VER-003)
- Compute checkpoint_hash from the constructed Checkpoint struct
- Derive signing_digest from the checkpoint data for BLS signing
- Compute score from the checkpoint and validator participation

## Acceptance Criteria

- [ ] EpochCheckpointData contains all 6 required fields with correct types
- [ ] EpochCheckpointSignMaterial contains checkpoint, score, and signing_digest
- [ ] epoch_checkpoint_sign_material_from_l2_blocks() correctly computes block_root
- [ ] epoch_checkpoint_sign_material_from_l2_blocks() correctly extracts state_root
- [ ] epoch_checkpoint_sign_material_from_l2_blocks() correctly computes withdrawals_root
- [ ] epoch_checkpoint_sign_material_from_l2_blocks() correctly computes checkpoint_hash
- [ ] epoch_checkpoint_sign_material_from_l2_blocks() correctly derives signing_digest
- [ ] All fields are publicly accessible

## Implementation Notes

- EpochCheckpointData is the minimum data needed to identify and verify a checkpoint
- EpochCheckpointSignMaterial adds the signing-specific fields needed by validators
- The signing_digest is the actual bytes that validators sign with their BLS private key
- network_id prevents cross-network replay attacks (a checkpoint from testnet cannot be replayed on mainnet)
- This builds on VER-001 (block_root) and VER-003 (withdrawals_root) as dependencies
