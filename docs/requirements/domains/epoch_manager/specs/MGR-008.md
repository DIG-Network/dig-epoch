## Summary

Defines the core instance methods and accessors on `EpochManager` that provide read access to the manager's state and utility methods for L1 height mapping and reward storage. These methods complement the mutation methods (MGR-002 through MGR-004) and the query methods (MGR-005).

## Specification

### Methods

| Method | Signature | Description |
|--------|-----------|-------------|
| `current_epoch()` | `(&self) -> u64` | Returns the current epoch number from the current EpochInfo. |
| `current_epoch_info()` | `(&self) -> EpochInfo` | Returns a clone of the current epoch's full state. |
| `current_phase()` | `(&self) -> EpochPhase` | Returns the current phase of the current epoch. |
| `genesis_l1_height()` | `(&self) -> u32` | Returns the network's genesis L1 height (immutable after construction). |
| `network_id()` | `(&self) -> &Bytes32` | Returns a reference to the network ID (immutable after construction). |
| `epoch_for_l1_height()` | `(&self, l1_height: u32) -> u64` | Maps an L1 height to its epoch number using genesis_l1_height. |
| `l1_range_for_epoch()` | `(&self, epoch: u64) -> (u32, u32)` | Returns (start_l1, end_l1) for the given epoch using genesis_l1_height. |
| `store_rewards()` | `(&self, distribution: RewardDistribution)` | Archives per-epoch reward distribution in the rewards map, keyed by epoch number. |

### Key Rules

- `current_epoch()`, `current_epoch_info()`, and `current_phase()` acquire a read lock on the current epoch state
- `genesis_l1_height()` and `network_id()` do not require locking (immutable fields)
- `epoch_for_l1_height()` computes `(l1_height - genesis_l1_height) / EPOCH_L1_BLOCKS`
- `l1_range_for_epoch()` delegates to the free function `l1_range_for_epoch(genesis_l1_height, epoch)`
- `store_rewards()` acquires a write lock on the rewards map

## Acceptance Criteria

- [ ] current_epoch() returns the current epoch number
- [ ] current_epoch_info() returns a clone of the current EpochInfo
- [ ] current_phase() returns the current EpochPhase
- [ ] genesis_l1_height() returns the genesis L1 height passed at construction
- [ ] network_id() returns a reference to the Bytes32 network ID
- [ ] epoch_for_l1_height() correctly maps L1 heights to epoch numbers
- [ ] l1_range_for_epoch() returns the correct (start, end) L1 heights
- [ ] store_rewards() stores distribution retrievable via get_rewards()
- [ ] All read methods work concurrently (no deadlocks)

## Implementation Notes

- current_epoch_info() clones the full EpochInfo, which includes the checkpoint Option and DFSP roots
- epoch_for_l1_height() and l1_range_for_epoch() are convenience wrappers that inject genesis_l1_height
- store_rewards() is typically called after compute_reward_distribution() during epoch finalization
