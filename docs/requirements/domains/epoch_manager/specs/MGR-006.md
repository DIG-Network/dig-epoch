## Summary

Defines the `set_current_epoch_dfsp_close_snapshot` method on `EpochManager` that attaches DFSP (Deterministic Fee-Split Protocol) close data to the current epoch before it is advanced. This data captures the DFSP state at the epoch boundary and is required for epoch finalization.

## Specification

### Function Signature

```rust
impl EpochManager {
    pub fn set_current_epoch_dfsp_close_snapshot(
        &self,
        snapshot: DfspCloseSnapshot,
    ) -> Result<()>
}
```

### Behavior

1. Acquires a write lock on the inner state.
2. Verifies the current phase is `Finalization`. If not, returns an appropriate error.
3. Sets the DFSP close snapshot on the current `EpochInfo`.
4. Returns `Ok(())`.

### Phase Requirement

The snapshot MUST only be set during the `Finalization` phase because DFSP close data is computed after checkpoint competition and before epoch advancement. Setting it in any other phase would violate the epoch lifecycle ordering.

## Acceptance Criteria

- [ ] Sets `DfspCloseSnapshot` on the current `EpochInfo`.
- [ ] Requires the current phase to be `Finalization`.
- [ ] Returns an error when called outside `Finalization` phase.
- [ ] Snapshot is accessible on the `EpochInfo` after being set.
- [ ] Snapshot is preserved when the epoch is archived as `EpochSummary`.

## Implementation Notes

- This method is called after the checkpoint competition winner is selected but before `advance_epoch()`.
- The `DfspCloseSnapshot` captures DFSP state transitions that occurred during the epoch.
- The snapshot becomes part of the `EpochSummary` when the epoch is archived.
