## Summary

Defines the `set_current_epoch_chain_totals` method on `EpochManager` that overwrites the block production statistics for the current epoch with absolute values. Unlike `record_block` which increments, this method sets exact values and is used for resync or correction scenarios.

## Specification

### Function Signature

```rust
impl EpochManager {
    pub fn set_current_epoch_chain_totals(&self, blocks: u32, fees: u64, txns: u64) {
        let mut inner = self.inner.write();
        inner.current_epoch.blocks_produced = blocks;
        inner.current_epoch.total_fees = fees;
        inner.current_epoch.total_transactions = txns;
    }
}
```

### Behavior

1. Acquires a write lock on the inner state.
2. Sets `blocks_produced` to `blocks` (overwrite, not increment).
3. Sets `total_fees` to `fees` (overwrite, not increment).
4. Sets `total_transactions` to `txns` (overwrite, not increment).

### Distinction from record_block

| Aspect       | `record_block`              | `set_current_epoch_chain_totals` |
|--------------|-----------------------------|----------------------------------|
| Operation    | Increments                  | Overwrites                       |
| Phase check  | Requires `BlockProduction`  | No phase restriction             |
| Use case     | Normal block recording      | Resync / correction              |
| blocks_produced | `+= 1`                  | `= blocks`                       |

## Acceptance Criteria

- [ ] `blocks_produced` is set to exactly `blocks` (not incremented).
- [ ] `total_fees` is set to exactly `fees` (not incremented).
- [ ] `total_transactions` is set to exactly `txns` (not incremented).
- [ ] Previous values are fully overwritten regardless of their prior state.
- [ ] No phase restriction is enforced.

## Implementation Notes

- This method does not enforce a phase check because it is used for resync/correction, which may occur at any point.
- The method is idempotent: calling it twice with the same arguments produces the same result.
- This is useful when a node restarts and needs to set the epoch's chain totals from persisted state.
