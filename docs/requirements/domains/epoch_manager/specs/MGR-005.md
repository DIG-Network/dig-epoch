## Summary

Defines the read-only query methods on `EpochManager` that allow external callers to inspect the current epoch state, retrieve historical summaries, compute aggregate statistics, and look up reward distributions.

## Specification

### get_epoch_info

```rust
impl EpochManager {
    pub fn get_epoch_info(&self) -> EpochInfo {
        self.inner.read().current_epoch.clone()
    }
}
```

Returns a clone of the current `EpochInfo`. The clone ensures callers get a snapshot that is not affected by subsequent mutations.

### get_epoch_summary

```rust
impl EpochManager {
    pub fn get_epoch_summary(&self, epoch: u64) -> Option<EpochSummary> {
        self.inner.read().summaries.iter()
            .find(|s| s.epoch == epoch)
            .cloned()
    }
}
```

Returns the `EpochSummary` for a specific completed epoch, or `None` if the epoch is not in history.

### recent_summaries

```rust
impl EpochManager {
    pub fn recent_summaries(&self, n: usize) -> Vec<EpochSummary> {
        let inner = self.inner.read();
        inner.summaries.iter().rev().take(n).rev().cloned().collect()
    }
}
```

Returns the last `n` summaries from the tail of the summaries vec, preserving epoch order.

### total_stats

```rust
impl EpochManager {
    pub fn total_stats(&self) -> EpochStats {
        // Aggregates across all completed epochs and the current epoch

```

Returns aggregate statistics across all epochs (completed summaries plus the current epoch).

### get_rewards

Returns the `RewardDistribution` for a specific epoch, or `None` if the epoch is not found or has no rewards.

## Acceptance Criteria

- [ ] `get_epoch_info()` returns a clone of the current `EpochInfo`.
- [ ] `get_epoch_info()` snapshot is not affected by subsequent mutations.
- [ ] `get_epoch_summary(epoch)` returns `Some(summary)` for completed epochs.
- [ ] `get_epoch_summary(epoch)` returns `None` for unknown epochs.
- [ ] `recent_summaries(n)` returns the last `n` summaries in epoch order.
- [ ] `recent_summaries(n)` returns fewer than `n` if fewer exist.
- [ ] `total_stats()` aggregates across all completed and current epochs.
- [ ] `get_rewards(epoch)` returns rewards for a completed epoch.
- [ ] `get_rewards(epoch)` returns `None` for unknown epochs.
- [ ] All query methods acquire read locks (concurrent reads allowed).

## Implementation Notes

- All query methods use read locks, allowing concurrent access.
- `get_epoch_info()` returns a clone to prevent callers from holding a reference to locked data.
- `recent_summaries` reverses, takes, and reverses again to preserve chronological order in the output.
- `total_stats` must include both completed epochs (from summaries) and the current in-progress epoch.
