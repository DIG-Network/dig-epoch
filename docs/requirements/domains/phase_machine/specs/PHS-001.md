## Summary

Defines the stateless function that maps L1 block height progress to an epoch phase. The function computes what percentage of the epoch's L1 window has elapsed and returns the corresponding `EpochPhase` variant. This is the core deterministic phase calculation used throughout the epoch lifecycle.

## Specification

### Function Signature

```rust
pub fn l1_progress_phase_for_network_epoch(
    genesis_l1_height: u32,
    epoch: u64,
    current_l1_height: u32,
) -> EpochPhase
```

### Phase Boundaries

The function computes L1 progress as a percentage of the epoch's L1 window (`EPOCH_L1_BLOCKS`) and maps it to a phase using the following constants:

| Constant                        | Value | Phase Boundary              |
|---------------------------------|-------|-----------------------------|
| `PHASE_BLOCK_PRODUCTION_END_PCT`| 50%   | BlockProduction ends        |
| `PHASE_CHECKPOINT_END_PCT`      | 75%   | Checkpoint ends             |
| `PHASE_FINALIZATION_END_PCT`    | 100%  | Finalization ends           |

### Phase Mapping

| L1 Progress            | Phase             |
|------------------------|-------------------|
| `< 50%`               | `BlockProduction` |
| `>= 50%` and `< 75%`  | `Checkpoint`      |
| `>= 75%` and `< 100%` | `Finalization`    |
| `>= 100%`             | `Complete`        |

### Properties

- The function is **pure**: no side effects, no state mutation.
- The function is **deterministic**: same inputs always produce the same output.
- No wall-clock time is used; only L1 block height drives phase progression.

## Acceptance Criteria

- [ ] Returns `BlockProduction` when L1 progress is below 50%.
- [ ] Returns `Checkpoint` when L1 progress is at or above 50% but below 75%.
- [ ] Returns `Finalization` when L1 progress is at or above 75% but below 100%.
- [ ] Returns `Complete` when L1 progress is at or above 100%.
- [ ] Function is pure with no side effects.
- [ ] Uses `PHASE_BLOCK_PRODUCTION_END_PCT`, `PHASE_CHECKPOINT_END_PCT`, and `PHASE_FINALIZATION_END_PCT` constants.

## Implementation Notes

- The epoch's L1 window start is computed from `genesis_l1_height` and `epoch` number.
- Progress percentage = `(current_l1_height - epoch_l1_start) / EPOCH_L1_BLOCKS * 100`.
- Boundary checks use the phase percentage constants, not hardcoded values.
