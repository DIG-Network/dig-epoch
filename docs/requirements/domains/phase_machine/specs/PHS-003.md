## Summary

Defines the epoch advancement readiness check, the `PhaseTransition` record structure, and the `EpochEvent::PhaseChanged` event that is emitted on every phase transition. Together these enable callers to detect when an epoch is ready to advance and to observe phase changes.

## Specification

### should_advance

```rust
impl EpochManager {
    pub fn should_advance(&self, l1_height: u32) -> bool {
        self.current_phase() == EpochPhase::Complete
    }
}
```

Returns `true` when the current phase is `Complete`, indicating the epoch is ready to advance.

### PhaseTransition

```rust
pub struct PhaseTransition {
    pub epoch: u64,
    pub from: EpochPhase,
    pub to: EpochPhase,
    pub l1_height: u32,
}
```

Records the details of a phase transition:

| Field       | Type         | Description                                    |
|-------------|--------------|------------------------------------------------|
| `epoch`     | `u64`        | The epoch number in which the transition occurred |
| `from`      | `EpochPhase` | The phase before the transition                |
| `to`        | `EpochPhase` | The phase after the transition                 |
| `l1_height` | `u32`        | The L1 block height that triggered the transition |

### EpochEvent::PhaseChanged

```rust
pub enum EpochEvent {
    PhaseChanged(PhaseTransition),
    // ... other variants
}
```

`EpochEvent::PhaseChanged` MUST be emitted whenever a phase transition occurs. The event wraps the `PhaseTransition` record.

## Acceptance Criteria

- [ ] `should_advance()` returns `true` when phase is `Complete`.
- [ ] `should_advance()` returns `false` for `BlockProduction`, `Checkpoint`, and `Finalization`.
- [ ] `PhaseTransition` contains `epoch`, `from`, `to`, and `l1_height` fields.
- [ ] `EpochEvent::PhaseChanged` is emitted on every phase transition.
- [ ] `EpochEvent::PhaseChanged` wraps the correct `PhaseTransition`.

## Implementation Notes

- `should_advance` checks only the current phase; it does not verify other preconditions for epoch advancement (those are checked in `advance_epoch`).
- `PhaseTransition` is created by `update_phase()` (PHS-002) and can be used to emit `EpochEvent::PhaseChanged`.
