# DFS-005: DFSP Activation Control

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)
> **Verification:** [VERIFICATION.md](../VERIFICATION.md)
> **Tracking:** [TRACKING.yaml](../TRACKING.yaml)
> **Spec reference:** [SPEC.md - Section 9.7](../../../../resources/SPEC.md)

## Summary

DFSP activation control provides a governance mechanism for enabling DFSP functionality on a network. The activation height determines when DFSP operations become valid. It defaults to `u64::MAX` (disabled), can be overridden via environment variable, and can be overridden at runtime for testing purposes.

## Specification

```rust
/// Returns the DFSP activation height for the current network.
/// Checks the DIG_DFSP_ACTIVATION_HEIGHT environment variable first;
/// falls back to DFSP_ACTIVATION_HEIGHT constant (u64::MAX = disabled).
pub fn dfsp_activation_height_for_network() -> u64

/// Returns true if DFSP is active at the given L2 height.
pub fn is_dfsp_active_at_height(height: u64) -> bool {
    height >= dfsp_activation_height_for_network()
}

/// Sets a runtime override for DFSP activation height (testing only).
/// When set to Some(height), dfsp_activation_height_for_network() returns
/// that height instead of reading the environment variable or constant.
/// When set to None, the override is cleared and normal resolution resumes.
pub fn set_dfsp_activation_height_override(height: Option<u64>)
```

Key rules:
- `dfsp_activation_height_for_network()` MUST return `DFSP_ACTIVATION_HEIGHT` by default (`u64::MAX`)
- When `DIG_DFSP_ACTIVATION_HEIGHT` environment variable is set, MUST parse and return that value
- `is_dfsp_active_at_height()` MUST return `height >= dfsp_activation_height_for_network()`
- DFSP operations MUST reject with `DfspNotActive` error if called before the activation height
- `set_dfsp_activation_height_override()` MUST override all other resolution (env var and constant)
- `set_dfsp_activation_height_override(None)` MUST clear the override

## Acceptance Criteria

- [ ] `dfsp_activation_height_for_network()` returns `u64::MAX` by default
- [ ] Setting `DIG_DFSP_ACTIVATION_HEIGHT` env var overrides the default
- [ ] `is_dfsp_active_at_height()` returns false below activation and true at/above
- [ ] DFSP operations reject with `DfspNotActive` before activation
- [ ] `set_dfsp_activation_height_override(Some(100))` causes `dfsp_activation_height_for_network()` to return `100`
- [ ] `set_dfsp_activation_height_override(None)` clears the override, restoring normal resolution

## Implementation Notes

- The runtime override (`set_dfsp_activation_height_override`) is intended for testing only and should use thread-local or atomic storage
- The resolution order is: runtime override > environment variable > constant default
- This is the gating mechanism for the entire DFSP subsystem -- no DFSP functions should operate before activation
