## Summary

EpochStats provides aggregate statistics across all epochs managed by the EpochManager. It is returned by `EpochManager::total_stats()` and gives a high-level overview of the chain's epoch history.

## Specification

```rust
#[derive(Debug, Clone, Default)]
pub struct EpochStats {
    pub total_epochs: u64,
    pub finalized_epochs: u64,
    pub total_blocks: u64,
    pub total_transactions: u64,
    pub total_fees: u64,
}
```

Key rules:
- All 5 fields MUST be `u64`
- The `Default` derive MUST zero all fields
- `total_epochs` counts both finalized and non-finalized epochs
- `finalized_epochs` counts only epochs that completed with a checkpoint
- `total_blocks`, `total_transactions`, and `total_fees` are sums across all managed epochs

## Acceptance Criteria

- [ ] EpochStats contains exactly 5 fields: total_epochs, finalized_epochs, total_blocks, total_transactions, total_fees
- [ ] All fields are u64
- [ ] EpochStats derives Debug, Clone, Default
- [ ] Default::default() returns an EpochStats with all fields set to 0
- [ ] All fields are publicly accessible
- [ ] EpochManager::total_stats() returns EpochStats with correct aggregates across all epochs

## Implementation Notes

- EpochStats is computed on-demand by iterating the epoch history, not maintained incrementally
- The current epoch's counters are included in the aggregation
- finalized_epochs counts epochs where `finalized == true` in the EpochSummary
