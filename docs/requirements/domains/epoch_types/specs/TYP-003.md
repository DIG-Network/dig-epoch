# TYP-003: EpochSummary Struct

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)
> **Verification:** [VERIFICATION.md](../VERIFICATION.md)
> **Tracking:** [TRACKING.yaml](../TRACKING.yaml)
> **Spec reference:** [SPEC.md - Section 3.5](../../../../resources/SPEC.md)

## Summary

EpochSummary is an immutable archive of a completed epoch. It is created from EpochInfo when `advance_epoch()` archives the current epoch. It stores the same DFSP close snapshot fields as EpochInfo but replaces the mutable counters and checkpoint with finalized summary values.

## Specification

EpochSummary MUST define the following structure:

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct EpochSummary {
    pub epoch: u64,
    pub blocks: u32,
    pub transactions: u64,
    pub fees: u64,
    pub finalized: bool,
    pub checkpoint_hash: Option<Bytes32>,

    // -- DFSP state at close --
    pub collateral_registry_root: Bytes32,
    pub cid_state_root: Bytes32,
    pub node_registry_root: Bytes32,
    pub namespace_epoch_root: Bytes32,
    pub dfsp_issuance_total: u64,
    pub active_cid_count: u32,
    pub active_node_count: u32,
}
```

When created from an EpochInfo:
- `epoch` MUST be copied from `EpochInfo::epoch`
- `blocks` MUST be copied from `EpochInfo::blocks_produced`
- `transactions` MUST be copied from `EpochInfo::total_transactions`
- `fees` MUST be copied from `EpochInfo::total_fees`
- `finalized` MUST be `EpochInfo::checkpoint.is_some()`
- `checkpoint_hash` MUST be `EpochInfo::checkpoint.map(|c| c.hash())`
- All seven DFSP fields MUST be copied directly from EpochInfo

## Acceptance Criteria

- [ ] EpochSummary contains all 13 fields with correct names and types
- [ ] EpochSummary derives Debug, Clone, Serialize, Deserialize
- [ ] epoch maps from EpochInfo::epoch
- [ ] blocks maps from EpochInfo::blocks_produced
- [ ] transactions maps from EpochInfo::total_transactions
- [ ] fees maps from EpochInfo::total_fees
- [ ] finalized is true when EpochInfo::checkpoint is Some, false when None
- [ ] checkpoint_hash is Some(hash) when checkpoint exists, None otherwise
- [ ] All seven DFSP fields are preserved from EpochInfo
- [ ] EpochSummary is immutable by convention (no mutator methods)

## Implementation Notes

- EpochSummary is the historical record -- once created, it does not change
- The conversion from EpochInfo to EpochSummary happens in `EpochManager::advance_epoch()`
- `checkpoint_hash` uses `Checkpoint::hash()` from dig-block to compute the hash
- Storing only the hash (not the full Checkpoint) reduces memory for long-running validators
- The distinction between mutable EpochInfo and immutable EpochSummary is a key design decision (Decision #10 in SPEC)
