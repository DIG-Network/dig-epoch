# TYP-004: DfspCloseSnapshot Struct

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)
> **Verification:** [VERIFICATION.md](../VERIFICATION.md)
> **Tracking:** [TRACKING.yaml](../TRACKING.yaml)
> **Spec reference:** [SPEC.md - Section 3.6](../../../../resources/SPEC.md)

## Summary

DfspCloseSnapshot captures the seven DFSP root and count fields at epoch close, before the epoch is archived. It is populated by the DFSP subsystem after epoch-boundary processing completes and applied to the current EpochInfo via `set_current_epoch_dfsp_close_snapshot()`.

## Specification

DfspCloseSnapshot MUST define the following structure:

```rust
#[derive(Debug, Clone, Copy)]
pub struct DfspCloseSnapshot {
    pub collateral_registry_root: Bytes32,
    pub cid_state_root: Bytes32,
    pub node_registry_root: Bytes32,
    pub namespace_epoch_root: Bytes32,
    pub dfsp_issuance_total: u64,
    pub active_cid_count: u32,
    pub active_node_count: u32,
}
```

The snapshot contains four Bytes32 Merkle roots (collateral registry, CID state, node registry, namespace epoch), one u64 issuance total, and two u32 counts (active CIDs, active nodes).

## Acceptance Criteria

- [ ] DfspCloseSnapshot contains all 7 fields with correct names and types
- [ ] DfspCloseSnapshot derives Debug, Clone, Copy
- [ ] Copy semantics work (assignment copies the value, not a reference)
- [ ] Four root fields are Bytes32 (chia-protocol)
- [ ] dfsp_issuance_total is u64
- [ ] active_cid_count and active_node_count are u32
- [ ] All fields are publicly accessible

## Implementation Notes

- Copy derive is appropriate because DfspCloseSnapshot contains only fixed-size fields (4 x Bytes32 + u64 + 2 x u32 = 148 bytes)
- The snapshot is applied to EpochInfo before archival (SPEC Design Decision #11)
- The DFSP subsystem creates this snapshot after running the seven-stage epoch-boundary pipeline
- Values in this snapshot override the default EMPTY_ROOT / 0 values in EpochInfo
- After application, the values survive into the EpochSummary when advance_epoch() archives the epoch
