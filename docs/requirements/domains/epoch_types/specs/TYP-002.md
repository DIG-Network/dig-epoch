# TYP-002: EpochInfo Struct

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)
> **Verification:** [VERIFICATION.md](../VERIFICATION.md)
> **Tracking:** [TRACKING.yaml](../TRACKING.yaml)
> **Spec reference:** [SPEC.md - Section 3.4](../../../../resources/SPEC.md)

## Summary

EpochInfo is the mutable state container for the current epoch. It tracks block production counters, fees, the current phase, the winning checkpoint, and DFSP close snapshot fields. It is the primary data structure managed by EpochManager during an epoch's lifecycle.

## Specification

EpochInfo MUST define the following structure:

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct EpochInfo {
    // -- Identity --
    pub epoch: u64,                            // Epoch number (0-indexed)
    pub start_l1_height: u32,                  // First L1 height in this epoch's window
    pub end_l1_height: u32,                    // Last L1 height in this epoch's window
    pub start_l2_height: u64,                  // First L2 block height in this epoch

    // -- Mutable counters --
    pub blocks_produced: u32,                  // L2 blocks recorded so far
    pub phase: EpochPhase,                     // Current phase
    pub total_fees: u64,                       // Accumulated fees (mojos)
    pub total_transactions: u64,               // Accumulated transaction count

    // -- State --
    pub checkpoint: Option<Checkpoint>,        // Winning checkpoint (set after finalization)
    pub start_state_root: Bytes32,             // CoinSet state root at epoch start

    // -- DFSP close snapshot --
    pub collateral_registry_root: Bytes32,     // Collateral registry SMT root at close
    pub cid_state_root: Bytes32,               // CID lifecycle state root at close
    pub node_registry_root: Bytes32,           // Node registry SMT root at close
    pub namespace_epoch_root: Bytes32,         // Cumulative namespace root at close
    pub dfsp_issuance_total: u64,              // Total DFSP issuance this epoch (mojos)
    pub active_cid_count: u32,                 // Active CIDs at close
    pub active_node_count: u32,                // Active storage nodes at close
}
```

The `new()` constructor MUST initialize:
- `phase` to `EpochPhase::BlockProduction`
- `blocks_produced`, `total_fees`, `total_transactions` to 0
- `checkpoint` to `None`
- `end_l1_height` to `start_l1_height + EPOCH_L1_BLOCKS`
- All four DFSP roots to `EMPTY_ROOT`
- `dfsp_issuance_total` to 0
- `active_cid_count` and `active_node_count` to 0

**Methods:**

| Method | Signature | Description |
|--------|-----------|-------------|
| `new()` | `(epoch, start_l1_height, start_l2_height, start_state_root) -> Self` | Creates a new epoch with BlockProduction phase and zeroed counters. DFSP roots default to EMPTY_ROOT. end_l1_height = start_l1_height + EPOCH_L1_BLOCKS. |
| `calculate_phase()` | `(&self, current_l1_height: u32) -> EpochPhase` | Deterministically computes phase from L1 progress percentage. |
| `target_blocks()` | `(&self) -> u64` | Returns BLOCKS_PER_EPOCH. |
| `can_produce_blocks()` | `(&self) -> bool` | True when phase is BlockProduction. |
| `can_submit_checkpoint()` | `(&self) -> bool` | True when phase is Checkpoint. |
| `is_complete()` | `(&self) -> bool` | True when phase is Complete. |
| `is_finalized()` | `(&self) -> bool` | True when checkpoint.is_some(). |
| `record_block()` | `(&mut self, fees: u64, tx_count: u64)` | Increments blocks_produced, total_fees, total_transactions. |
| `set_checkpoint()` | `(&mut self, checkpoint: Checkpoint)` | Sets the winning checkpoint. |
| `progress_percentage()` | `(&self, current_l1_height: u32) -> u32` | Returns 0-100 based on L1 progress within the epoch window. |

## Acceptance Criteria

- [ ] EpochInfo contains all 17 fields with correct names and types
- [ ] EpochInfo derives Debug, Clone, Serialize, Deserialize
- [ ] new() initializes phase to BlockProduction
- [ ] new() zeroes blocks_produced, total_fees, total_transactions
- [ ] new() sets checkpoint to None
- [ ] new() computes end_l1_height as start_l1_height + EPOCH_L1_BLOCKS
- [ ] new() sets all four DFSP roots to EMPTY_ROOT
- [ ] new() sets dfsp_issuance_total, active_cid_count, active_node_count to 0
- [ ] All fields are publicly accessible
- [ ] Checkpoint field uses dig-block::Checkpoint type
- [ ] Hash fields use chia-protocol::Bytes32 type
- [ ] calculate_phase() returns correct phase based on L1 progress percentage
- [ ] target_blocks() returns BLOCKS_PER_EPOCH (32)
- [ ] can_produce_blocks() returns true only when phase is BlockProduction
- [ ] can_submit_checkpoint() returns true only when phase is Checkpoint
- [ ] is_complete() returns true only when phase is Complete
- [ ] is_finalized() returns true only when checkpoint is Some
- [ ] record_block() increments blocks_produced, total_fees, total_transactions
- [ ] set_checkpoint() sets the checkpoint field
- [ ] progress_percentage() returns 0-100 based on L1 progress

## Implementation Notes

- EpochInfo is mutable state for the **current** epoch only; completed epochs are archived as EpochSummary (TYP-003)
- The DFSP close snapshot fields default to EMPTY_ROOT / 0 and are populated late in the epoch lifecycle via `set_current_epoch_dfsp_close_snapshot()`
- `Checkpoint` is imported from `dig-block`, not redefined here
- `Bytes32` is imported from `chia-protocol`
- `EPOCH_L1_BLOCKS` and `EMPTY_ROOT` come from the constants domain
- The `phase` field is updated by the phase state machine as L1 progresses
