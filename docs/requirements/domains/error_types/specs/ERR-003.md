# ERR-003: Error Conversions and Display

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)
> **Verification:** [VERIFICATION.md](../VERIFICATION.md)
> **Tracking:** [TRACKING.yaml](../TRACKING.yaml)
> **Spec reference:** [SPEC.md - Section 10](../../../../resources/SPEC.md)

## Summary

EpochError implements `From<CheckpointCompetitionError>` via the `#[from]` attribute on the Competition variant, enabling seamless error propagation with the `?` operator. Both error types implement `Display` via thiserror attributes with messages matching the SPEC definitions.

## Specification

The `#[from]` attribute on `EpochError::Competition` MUST generate:

```rust
impl From<CheckpointCompetitionError> for EpochError {
    fn from(err: CheckpointCompetitionError) -> Self {
        EpochError::Competition(err)
    }
}
```

Both EpochError and CheckpointCompetitionError MUST implement `std::fmt::Display` via their `#[error(...)]` attributes. The display messages are specified in ERR-001 and ERR-002 respectively.

## Acceptance Criteria

- [ ] `From<CheckpointCompetitionError> for EpochError` is implemented
- [ ] Converting CheckpointCompetitionError::NotStarted produces EpochError::Competition(NotStarted)
- [ ] Converting CheckpointCompetitionError::AlreadyFinalized produces EpochError::Competition(AlreadyFinalized)
- [ ] The `?` operator works to propagate CheckpointCompetitionError into Result<T, EpochError>
- [ ] EpochError::Competition displays as "Competition error: {inner_display}"
- [ ] All EpochError variants produce correct Display output
- [ ] All CheckpointCompetitionError variants produce correct Display output

## Implementation Notes

- The `#[from]` attribute is a thiserror feature that generates the From impl automatically
- This conversion pattern allows functions returning `Result<T, EpochError>` to call functions returning `Result<T, CheckpointCompetitionError>` with `?`
- The Display impl chains: `EpochError::Competition` displays as "Competition error: " followed by the inner error's Display
