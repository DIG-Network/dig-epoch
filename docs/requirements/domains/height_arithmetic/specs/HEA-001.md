# HEA-001: epoch_for_block_height

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)
> **Verification:** [VERIFICATION.md](../VERIFICATION.md)
> **Tracking:** [TRACKING.yaml](../TRACKING.yaml)
> **Spec reference:** [SPEC.md - Section 5.1](../../../../resources/SPEC.md)

## Summary

`epoch_for_block_height` is a stateless pure function that maps any valid L2 block height to its epoch number. The formula uses integer division with a height-1 offset to account for the genesis block starting at height 1 (not 0). This is the fundamental mapping function that all other height-epoch conversions depend on.

## Specification

```rust
/// Maps an L2 block height to its epoch number.
///
/// Formula: (height - 1) / BLOCKS_PER_EPOCH
///
/// Height 1 is genesis (epoch 0). Each epoch contains BLOCKS_PER_EPOCH (32) blocks.
/// The function is stateless and can be called from any context.
pub fn epoch_for_block_height(height: u64) -> u64 {
    (height - 1) / BLOCKS_PER_EPOCH
}
```

Height-to-epoch mapping with BLOCKS_PER_EPOCH = 32:

| Height | Epoch | Calculation |
|--------|-------|-------------|
| 1 | 0 | (1-1)/32 = 0 |
| 32 | 0 | (32-1)/32 = 0 |
| 33 | 1 | (33-1)/32 = 1 |
| 64 | 1 | (64-1)/32 = 1 |
| 65 | 2 | (65-1)/32 = 2 |

The function requires `height >= 1` (GENESIS_HEIGHT). Behavior for height 0 is undefined (would underflow in debug builds).

## Acceptance Criteria

- [ ] Function signature is `epoch_for_block_height(height: u64) -> u64`
- [ ] Returns 0 for height 1 (genesis)
- [ ] Returns 0 for height 32 (last block of epoch 0)
- [ ] Returns 1 for height 33 (first block of epoch 1)
- [ ] Returns 1 for height 64 (last block of epoch 1)
- [ ] Returns 2 for height 65 (first block of epoch 2)
- [ ] Correct for large heights (e.g., h=1,000,000)
- [ ] Function is stateless with no side effects
- [ ] Uses BLOCKS_PER_EPOCH constant (not a hardcoded 32)

## Implementation Notes

- The height-1 offset is because genesis is at height 1, not height 0 (SPEC Design Decision #3)
- BLOCKS_PER_EPOCH is 32 (from the constants domain)
- This function is used extensively by the epoch manager, phase state machine, and checkpoint detection
- The function has no error case for valid inputs -- heights below 1 are a precondition violation
- Integer division truncates toward zero, which correctly maps ranges of 32 heights to each epoch
