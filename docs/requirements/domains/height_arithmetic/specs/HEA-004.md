# HEA-004: L1 Range for Epoch

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)
> **Verification:** [VERIFICATION.md](../VERIFICATION.md)
> **Tracking:** [TRACKING.yaml](../TRACKING.yaml)
> **Spec reference:** [SPEC.md - Section 5.4](../../../../resources/SPEC.md)

## Summary

`l1_range_for_epoch` computes the L1 block height range for a given epoch's L1 window. The L1 range determines which L1 blocks are monitored for phase progression during the epoch. Each epoch's L1 window is EPOCH_L1_BLOCKS (32) blocks wide, starting from the network's genesis L1 height.

## Specification

```rust
/// Returns the (start_l1_height, end_l1_height) for a given epoch,
/// given the network's genesis L1 height.
///
/// The range is inclusive: both start and end heights are part of the epoch's window.
/// Each epoch's window is EPOCH_L1_BLOCKS wide.
pub fn l1_range_for_epoch(genesis_l1_height: u32, epoch: u64) -> (u32, u32) {
    let start = genesis_l1_height + (epoch as u32 * EPOCH_L1_BLOCKS);
    let end = genesis_l1_height + ((epoch as u32 + 1) * EPOCH_L1_BLOCKS) - 1;
    (start, end)
}
```

Example mappings with genesis_l1_height = 100 and EPOCH_L1_BLOCKS = 32:

| Epoch | Start L1 | End L1 | Width |
|-------|----------|--------|-------|
| 0 | 100 | 131 | 32 |
| 1 | 132 | 163 | 32 |
| 2 | 164 | 195 | 32 |

## Acceptance Criteria

- [ ] Function signature is `l1_range_for_epoch(genesis_l1_height: u32, epoch: u64) -> (u32, u32)`
- [ ] genesis=100, epoch=0 returns (100, 131)
- [ ] genesis=100, epoch=1 returns (132, 163)
- [ ] genesis=100, epoch=2 returns (164, 195)
- [ ] Range width (end - start + 1) equals EPOCH_L1_BLOCKS for all epochs
- [ ] Consecutive epochs have contiguous non-overlapping L1 ranges
- [ ] Function uses EPOCH_L1_BLOCKS constant
- [ ] Function is stateless with no side effects

## Implementation Notes

- EPOCH_L1_BLOCKS is 32, matching BLOCKS_PER_EPOCH (SPEC Design Decision #2)
- 32 L1 blocks at ~18 seconds per Chia block gives ~10 minutes per epoch L1 window
- The L1 range is used by the phase state machine to calculate what percentage of the L1 window has elapsed
- The range is inclusive on both endpoints: start and end heights are both part of the epoch's window
- EpochInfo uses the start from this function as `start_l1_height` and computes `end_l1_height = start_l1_height + EPOCH_L1_BLOCKS`
