# HEA-005: Round-Trip Identity

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)
> **Verification:** [VERIFICATION.md](../VERIFICATION.md)
> **Tracking:** [TRACKING.yaml](../TRACKING.yaml)
> **Spec reference:** [SPEC.md - Section 14.10](../../../../resources/SPEC.md)

## Summary

The round-trip identity property validates internal consistency of the height-epoch conversion functions. For any valid L2 block height h >= 1, the height must fall within the inclusive range defined by its epoch's first height and checkpoint height. This is a property test requirement that exercises the relationship between `epoch_for_block_height`, `first_height_in_epoch`, and `epoch_checkpoint_height`.

## Specification

For all valid heights h >= 1:

```rust
// Property: every height falls within its epoch's range
let epoch = epoch_for_block_height(h);
let first = first_height_in_epoch(epoch);
let checkpoint = epoch_checkpoint_height(epoch);
assert!(first <= h && h <= checkpoint);
```

Additionally, the following derived properties MUST hold:

```rust
// Property: first height maps back to its epoch
assert_eq!(epoch_for_block_height(first_height_in_epoch(e)), e);

// Property: checkpoint height maps back to its epoch
assert_eq!(epoch_for_block_height(epoch_checkpoint_height(e)), e);

// Property: checkpoint = first + BLOCKS_PER_EPOCH - 1
assert_eq!(
    epoch_checkpoint_height(e),
    first_height_in_epoch(e) + BLOCKS_PER_EPOCH - 1
);
```

## Acceptance Criteria

- [ ] For all h in 1..=1,000,000: first_height_in_epoch(epoch_for_block_height(h)) <= h
- [ ] For all h in 1..=1,000,000: h <= epoch_checkpoint_height(epoch_for_block_height(h))
- [ ] For all e in 0..=10,000: epoch_for_block_height(first_height_in_epoch(e)) == e
- [ ] For all e in 0..=10,000: epoch_for_block_height(epoch_checkpoint_height(e)) == e
- [ ] For all e in 0..=10,000: epoch_checkpoint_height(e) == first_height_in_epoch(e) + BLOCKS_PER_EPOCH - 1
- [ ] Boundary heights (first and last of each epoch) satisfy the property

## Implementation Notes

- This requirement is a property test, not a function to implement -- it validates the correctness of HEA-001 and HEA-002
- Property tests should use a range of values including small epochs (0-10), medium epochs (100-110), and large epochs (10000+)
- Boundary values are especially important: first and last heights of each epoch
- The round-trip property is the fundamental invariant that ensures the height-epoch mapping is bijective at the epoch granularity
- This property is listed in SPEC Section 14.10 as a required property test
