# HEA-006: last_committed_height_in_epoch

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)
> **Verification:** [VERIFICATION.md](../VERIFICATION.md)
> **Tracking:** [TRACKING.yaml](../TRACKING.yaml)
> **Spec reference:** [SPEC.md - Section 5.5](../../../../resources/SPEC.md)

## Summary

`last_committed_height_in_epoch` caps the last L2 height included in an epoch's checkpoint at the epoch checkpoint height. Even if the chain tip is higher, the function prevents namespace rollup and other epoch-scoped operations from including blocks that belong to the next epoch.

## Specification

```rust
/// Returns the last L2 height that should be included in this epoch's
/// checkpoint. Caps at the epoch checkpoint height, even if the chain
/// tip is higher. Prevents namespace rollup from bleeding into the
/// next epoch.
pub fn last_committed_height_in_epoch(epoch: u64, tip_height: u64) -> u64 {
    let ckp = epoch_checkpoint_height(epoch);
    std::cmp::min(tip_height, ckp)
}
```

## Acceptance Criteria

- [ ] Returns tip_height when tip_height < epoch_checkpoint_height(epoch)
- [ ] Returns epoch_checkpoint_height(epoch) when tip_height == epoch_checkpoint_height(epoch)
- [ ] Returns epoch_checkpoint_height(epoch) when tip_height > epoch_checkpoint_height(epoch)
- [ ] For epoch 0 with tip_height 20, returns 20 (tip < 32)
- [ ] For epoch 0 with tip_height 32, returns 32 (tip == checkpoint)
- [ ] For epoch 0 with tip_height 50, returns 32 (tip > checkpoint, capped)
- [ ] For epoch 1 with tip_height 64, returns 64
- [ ] For epoch 1 with tip_height 100, returns 64

## Implementation Notes

- This function is used during namespace rollup (DFS-006) and checkpoint signing (VER-004) to scope operations to the current epoch
- It is a pure function with no side effects
- Uses epoch_checkpoint_height() from HEA-002
