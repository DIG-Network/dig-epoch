# HEA-002: first_height and checkpoint_height

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)
> **Verification:** [VERIFICATION.md](../VERIFICATION.md)
> **Tracking:** [TRACKING.yaml](../TRACKING.yaml)
> **Spec reference:** [SPEC.md - Section 5.1](../../../../resources/SPEC.md)

## Summary

`first_height_in_epoch` and `epoch_checkpoint_height` are the inverse functions of `epoch_for_block_height`. Together they define the inclusive range of L2 block heights that belong to a given epoch. The first height is the first block produced in the epoch; the checkpoint height is the last block (the empty checkpoint block).

## Specification

```rust
/// Returns the first L2 block height in the given epoch.
///
/// Formula: epoch * BLOCKS_PER_EPOCH + 1
///
/// Epoch 0 starts at height 1 (genesis). Each subsequent epoch
/// starts immediately after the previous epoch's checkpoint block.
pub fn first_height_in_epoch(epoch: u64) -> u64 {
    epoch * BLOCKS_PER_EPOCH + 1
}

/// Returns the checkpoint (last) L2 block height in the given epoch.
///
/// Formula: (epoch + 1) * BLOCKS_PER_EPOCH
///
/// The checkpoint block is the last block of the epoch and must be empty
/// (zero SpendBundles, zero cost, zero fees).
pub fn epoch_checkpoint_height(epoch: u64) -> u64 {
    (epoch + 1) * BLOCKS_PER_EPOCH
}
```

Epoch-to-height mapping with BLOCKS_PER_EPOCH = 32:

| Epoch | first_height_in_epoch | epoch_checkpoint_height | Range |
|-------|----------------------|------------------------|-------|
| 0 | 1 | 32 | [1, 32] |
| 1 | 33 | 64 | [33, 64] |
| 2 | 65 | 96 | [65, 96] |

## Acceptance Criteria

- [ ] first_height_in_epoch signature is `(epoch: u64) -> u64`
- [ ] epoch_checkpoint_height signature is `(epoch: u64) -> u64`
- [ ] first_height_in_epoch(0) returns 1
- [ ] first_height_in_epoch(1) returns 33
- [ ] first_height_in_epoch(2) returns 65
- [ ] epoch_checkpoint_height(0) returns 32
- [ ] epoch_checkpoint_height(1) returns 64
- [ ] epoch_checkpoint_height(2) returns 96
- [ ] Inverse relationship: epoch_for_block_height(first_height_in_epoch(e)) == e for all e
- [ ] Inverse relationship: epoch_for_block_height(epoch_checkpoint_height(e)) == e for all e
- [ ] Both functions are stateless with no side effects
- [ ] Both use BLOCKS_PER_EPOCH constant

## Implementation Notes

- Each epoch contains exactly BLOCKS_PER_EPOCH (32) blocks: epoch_checkpoint_height(e) - first_height_in_epoch(e) + 1 == BLOCKS_PER_EPOCH
- The checkpoint height equals first_height_in_epoch(e) + BLOCKS_PER_EPOCH - 1 (SPEC Property 14.10)
- These functions are used by EpochInfo::new() to compute start/end L2 heights
- The inverse relationship with epoch_for_block_height is critical for correctness and is validated by HEA-005
