# HEA-003: Checkpoint Block Detection

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)
> **Verification:** [VERIFICATION.md](../VERIFICATION.md)
> **Tracking:** [TRACKING.yaml](../TRACKING.yaml)
> **Spec reference:** [SPEC.md - Sections 5.2, 5.3](../../../../resources/SPEC.md)

## Summary

Checkpoint block detection identifies blocks that serve as epoch boundaries. The genesis block (height 1) and every epoch's last block (height 32, 64, 96, ...) are checkpoint-class blocks. Checkpoint-class blocks MUST be empty (zero SpendBundles, zero cost, zero fees). The `ensure_checkpoint_block_empty` guard enforces this invariant.

## Specification

```rust
/// Returns true if the given height is the genesis checkpoint block.
pub fn is_genesis_checkpoint_block(height: u64) -> bool {
    height == GENESIS_HEIGHT  // height == 1
}

/// Returns true if the given height is an epoch checkpoint block (last block).
pub fn is_epoch_checkpoint_block(height: u64) -> bool {
    height % BLOCKS_PER_EPOCH == 0  // height = 32, 64, 96, ...
}

/// Returns true if the given height is a checkpoint-class block
/// (genesis OR epoch checkpoint).
pub fn is_checkpoint_class_block(height: u64) -> bool {
    is_genesis_checkpoint_block(height) || is_epoch_checkpoint_block(height)
}

/// Enforces the empty-checkpoint-block invariant.
///
/// Returns Ok(()) for non-checkpoint heights regardless of parameters.
/// Returns Err(EpochError::CheckpointBlockNotEmpty) if any count is non-zero
/// at a checkpoint-class height.
pub fn ensure_checkpoint_block_empty(
    height: u64,
    spend_bundle_count: u32,
    total_cost: u64,
    total_fees: u64,
) -> Result<(), EpochError> {
    if is_checkpoint_class_block(height) {
        if spend_bundle_count != 0 || total_cost != 0 || total_fees != 0 {
            return Err(EpochError::CheckpointBlockNotEmpty(
                height, spend_bundle_count, total_cost, total_fees,
            ));
        }
    }
    Ok(())
}
```

Checkpoint-class heights with BLOCKS_PER_EPOCH = 32:
- Height 1 (genesis): checkpoint-class = true
- Height 2-31: checkpoint-class = false
- Height 32 (epoch 0 checkpoint): checkpoint-class = true
- Height 33-63: checkpoint-class = false
- Height 64 (epoch 1 checkpoint): checkpoint-class = true

## Implementation Notes

- The empty-checkpoint-block invariant (SPEC Design Decision #4) provides a clean state boundary for epoch summarization
- Checkpoint blocks carry zero SpendBundles so the checkpoint reflects the state root after all transactions without interleaving new ones
- The genesis block at height 1 is treated as the epoch-0 checkpoint for initial chain bootstrapping
- `is_epoch_checkpoint_block` uses modulo arithmetic for O(1) detection
- EpochError::CheckpointBlockNotEmpty carries all four values for diagnostic purposes
