# SER-003: Round-Trip Integrity

## Summary

For all serializable types, `from_bytes(to_bytes(x))` MUST equal `x`. No data loss is permitted through serialization round-trips. This property must be verified using property-based testing across all 6 serializable types.

## Implementation Notes

- Property-based testing generates thousands of random inputs, providing much stronger guarantees than hand-written test cases. Use `proptest` with at least the default number of cases (256).
- All types must derive `PartialEq` (and ideally `Debug`) for property test assertions.
- If `Arbitrary` is complex to implement for nested types, consider using `proptest-derive` or manual strategy composition.
- Edge cases to pay special attention to: `Bytes32` fields with all zeros or all ones; `Vec` fields that are empty; `Option` fields that are `None` and `Some`; maximum u64 values; `CheckpointCompetition` with different status variants and varying numbers of submissions.
- `DfspCloseSnapshot` is a Copy type with 7 fields -- its Arbitrary implementation should be straightforward since all fields are primitive types or `Bytes32`.
