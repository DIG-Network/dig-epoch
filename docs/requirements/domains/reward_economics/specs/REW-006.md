# REW-006: Halving Boundaries

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)
> **Verification:** [VERIFICATION.md](../VERIFICATION.md)
> **Tracking:** [TRACKING.yaml](../TRACKING.yaml)
> **Spec reference:** [SPEC.md - Section 8.1](../../../../resources/SPEC.md)

## Summary

Defines the halving interval constants and verifies that the 4-halving schedule produces the correct reward progression from 0.32 L2 down to 0.02 L2 tail emission. Halvings occur at fixed block intervals corresponding to approximately 3 years of block production at 3-second block times.

## Specification

### Constants

| Constant                    | Value       | Description                                      |
|-----------------------------|-------------|--------------------------------------------------|
| `HALVING_INTERVAL_BLOCKS`   | ~94.6M      | Number of blocks between halvings                |
| `HALVING_INTERVAL_EPOCHS`   | 315_576     | Number of epochs between halvings                |
| `HALVINGS_BEFORE_TAIL`      | 4           | Total halvings before permanent tail emission    |
| `INITIAL_BLOCK_REWARD`      | 0.32 L2     | Starting block reward (in mojos)                 |
| `TAIL_BLOCK_REWARD`         | 0.02 L2     | Permanent tail emission (in mojos)               |

### Halving Schedule

| Halving # | Reward   | Block Range Start                | Approximate Period |
|-----------|----------|----------------------------------|--------------------|
| 0         | 0.32 L2  | 1                                | Years 0-3          |
| 1         | 0.16 L2  | HALVING_INTERVAL_BLOCKS + 1      | Years 3-6          |
| 2         | 0.08 L2  | 2 * HALVING_INTERVAL_BLOCKS + 1  | Years 6-9          |
| 3         | 0.04 L2  | 3 * HALVING_INTERVAL_BLOCKS + 1  | Years 9-12         |
| 4 (tail)  | 0.02 L2  | 4 * HALVING_INTERVAL_BLOCKS + 1  | Year 12+           |

### Boundary Behavior

- At the last block of a halving period (height `N * HALVING_INTERVAL_BLOCKS`), the reward is still at the current halving level.
- At the first block of the next period (height `N * HALVING_INTERVAL_BLOCKS + 1`), the reward halves.
- This is because `halvings = (height - 1) / HALVING_INTERVAL_BLOCKS`: the subtraction of 1 ensures height 1 maps to halving 0.

### Relationship Between Intervals

`HALVING_INTERVAL_BLOCKS = HALVING_INTERVAL_EPOCHS * BLOCKS_PER_EPOCH`

Where `BLOCKS_PER_EPOCH = 32` (or the configured epoch size).

## Acceptance Criteria

- [ ] Reward at height 1 is 0.32 L2 (INITIAL_BLOCK_REWARD).
- [ ] Reward at height `HALVING_INTERVAL_BLOCKS` is 0.32 L2 (still in period 0).
- [ ] Reward at height `HALVING_INTERVAL_BLOCKS + 1` is 0.16 L2 (first halving).
- [ ] Reward at height `2 * HALVING_INTERVAL_BLOCKS + 1` is 0.08 L2 (second halving).
- [ ] Reward at height `3 * HALVING_INTERVAL_BLOCKS + 1` is 0.04 L2 (third halving).
- [ ] Reward at height `4 * HALVING_INTERVAL_BLOCKS + 1` is 0.02 L2 (tail emission).
- [ ] Reward never goes below 0.02 L2 at any height.
- [ ] `HALVING_INTERVAL_EPOCHS` equals 315_576.
- [ ] `HALVING_INTERVAL_BLOCKS = HALVING_INTERVAL_EPOCHS * BLOCKS_PER_EPOCH`.

## Implementation Notes

- The ~3-year halving interval at 3-second block times: `94,584,576 blocks / (365.25 * 24 * 3600 / 3) ~= 3 years`.
- `HALVING_INTERVAL_EPOCHS = 315_576` and `315_576 * 32 = 10_098_432` (if BLOCKS_PER_EPOCH=32) or the actual block interval if different epoch sizes are used.
- The 4-halving schedule (0.32 -> 0.02) is a factor of 16 reduction total (2^4 = 16, 0.32/16 = 0.02).
- Each halving exactly divides the reward by 2 using the `>> halvings` bit-shift.
