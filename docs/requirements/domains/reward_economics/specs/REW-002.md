# REW-002: total_block_reward with Bonus

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)
> **Verification:** [VERIFICATION.md](../VERIFICATION.md)
> **Tracking:** [TRACKING.yaml](../TRACKING.yaml)
> **Spec reference:** [SPEC.md - Section 8.2](../../../../resources/SPEC.md)

## Summary

Defines the `total_block_reward` function that computes the full reward for a block, including the base reward from the halving schedule and an optional bonus for the first block of a new epoch (the block immediately following a checkpoint).

## Specification

```rust
pub fn total_block_reward(height: u64, is_first_of_epoch: bool) -> u64 {
    block_reward_at_height(height) + if is_first_of_epoch {
        EPOCH_FIRST_BLOCK_BONUS
    } else {
        0
    }
}
```

### Constants

| Constant                  | Value           | Description                                |
|---------------------------|-----------------|--------------------------------------------|
| `EPOCH_FIRST_BLOCK_BONUS` | 0.1 L2 (mojos)  | Bonus for first block after checkpoint    |

- The function delegates to `block_reward_at_height` for the base reward.
- When `is_first_of_epoch` is `true`, the `EPOCH_FIRST_BLOCK_BONUS` (0.1 L2) is added.
- The bonus incentivizes timely block production after epoch transitions.

## Acceptance Criteria

- [ ] Returns `block_reward_at_height(height)` when `is_first_of_epoch` is `false`.
- [ ] Returns `block_reward_at_height(height) + EPOCH_FIRST_BLOCK_BONUS` when `is_first_of_epoch` is `true`.
- [ ] `EPOCH_FIRST_BLOCK_BONUS` equals 0.1 L2 in mojos.
- [ ] Bonus applies regardless of halving period.
- [ ] Bonus applies at tail emission heights.
- [ ] No overflow occurs when adding bonus to base reward.

## Implementation Notes

- The bonus creates a small economic incentive for validators to produce the first block of a new epoch promptly.
- `is_first_of_epoch` is determined by the caller based on whether the previous block was the last of the prior epoch (checkpoint boundary).
- The function remains pure and deterministic.
