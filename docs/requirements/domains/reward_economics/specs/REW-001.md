# REW-001: block_reward_at_height with Halving

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)

> **Tracking:** [TRACKING.yaml](../TRACKING.yaml)

## Summary

Defines the `block_reward_at_height` function that computes the per-block reward based on a 4-halving schedule. The reward starts at `INITIAL_BLOCK_REWARD` (0.32 L2) and halves at fixed intervals until reaching `TAIL_BLOCK_REWARD` (0.02 L2) as permanent tail emission. All values are expressed in mojos.

## Specification

```rust
pub fn block_reward_at_height(height: u64) -> u64 {
    let halvings = (height - 1) / HALVING_INTERVAL_BLOCKS;
    if halvings >= HALVINGS_BEFORE_TAIL {
        TAIL_BLOCK_REWARD
    } else {
        INITIAL_BLOCK_REWARD >> halvings
    }
}
```

### Constants

| Constant                  | Value         | Description                                    |
|---------------------------|---------------|------------------------------------------------|
| `INITIAL_BLOCK_REWARD`    | 0.32 L2 (mojos) | Starting per-block reward                   |
| `HALVING_INTERVAL_BLOCKS` | ~94.6M blocks | Blocks between halvings (~3 years at 3s/block) |
| `HALVINGS_BEFORE_TAIL`    | 4             | Number of halvings before tail emission        |
| `TAIL_BLOCK_REWARD`       | 0.02 L2 (mojos) | Permanent tail emission per block           |

### Halving Schedule

| Halving | Block Reward | Period     |
|---------|-------------|------------|
| 0       | 0.32 L2     | Years 0-3  |
| 1       | 0.16 L2     | Years 3-6  |
| 2       | 0.08 L2     | Years 6-9  |
| 3       | 0.04 L2     | Years 9-12 |
| 4+      | 0.02 L2     | Year 12+   |

- The halving count is computed as `(height - 1) / HALVING_INTERVAL_BLOCKS`, using `height - 1` so that height 1 (genesis) falls in halving 0.
- After `HALVINGS_BEFORE_TAIL` (4) halvings, the reward permanently remains at `TAIL_BLOCK_REWARD`.
- The bit-shift `>>` operator is used for efficient halving of the integer reward value.

## Acceptance Criteria

- [ ] Returns `INITIAL_BLOCK_REWARD` at height 1.
- [ ] Returns `INITIAL_BLOCK_REWARD` at the last block before the first halving.
- [ ] Returns `INITIAL_BLOCK_REWARD >> 1` at the first halving boundary.
- [ ] Returns `INITIAL_BLOCK_REWARD >> 2` at the second halving boundary.
- [ ] Returns `INITIAL_BLOCK_REWARD >> 3` at the third halving boundary.
- [ ] Returns `TAIL_BLOCK_REWARD` at and beyond the fourth halving boundary.
- [ ] All return values are in mojos.
- [ ] Uses `(height - 1) / HALVING_INTERVAL_BLOCKS` for halving computation.

## Implementation Notes

- All monetary values are stored as `u64` in mojos (smallest unit) to avoid floating-point precision issues.
- The `>> halvings` bit-shift is equivalent to dividing by `2^halvings`, providing exact integer halving.
- Height is 1-based (genesis block is height 1), hence the `height - 1` in the formula.
- This function is pure and deterministic -- same height always yields same reward.
