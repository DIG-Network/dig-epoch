# REW-005: Tail Emission Floor

> **Authoritative requirement:** [NORMATIVE.md](../NORMATIVE.md)
> **Verification:** [VERIFICATION.md](../VERIFICATION.md)
> **Tracking:** [TRACKING.yaml](../TRACKING.yaml)
> **Spec reference:** [SPEC.md - Section 8.1](../../../../resources/SPEC.md)

## Summary

Defines the minimum epoch reward floor that ensures economic viability after all halvings complete. Although tail emission yields only `0.02 L2/block * 32 blocks/epoch = 0.64 L2/epoch`, the floor guarantees a minimum of 2 L2 per epoch, preventing rewards from becoming negligibly small.

## Specification

### Constants

| Constant                | Value          | Description                            |
|-------------------------|----------------|----------------------------------------|
| `MINIMUM_EPOCH_REWARD`  | 2 L2 (mojos)   | Floor for total epoch reward           |
| `TAIL_BLOCK_REWARD`     | 0.02 L2 (mojos)| Per-block reward after all halvings    |
| `BLOCKS_PER_EPOCH`      | 32             | Blocks in one epoch                    |

### Floor Logic

The epoch reward floor MUST be applied when computing total epoch rewards:

```rust
pub fn epoch_reward_with_floor(computed_epoch_reward: u64) -> u64 {
    computed_epoch_reward.max(MINIMUM_EPOCH_REWARD)
}
```

- At tail emission: `32 blocks * 0.02 L2/block = 0.64 L2` per epoch (below the floor).
- The floor enforces: `max(0.64 L2, 2 L2) = 2 L2`.
- The floor MUST be applied after summing all block rewards in the epoch.
- The floor MUST NOT affect per-block reward computation (only the epoch total).

## Acceptance Criteria

- [ ] Epoch reward never falls below `MINIMUM_EPOCH_REWARD` (2 L2 in mojos).
- [ ] At tail emission, raw epoch reward is `32 * TAIL_BLOCK_REWARD = 0.64 L2`.
- [ ] Floor correctly raises 0.64 L2 to 2 L2.
- [ ] Floor does not affect epoch rewards that are already above 2 L2.
- [ ] Floor applies to the epoch total, not individual block rewards.
- [ ] `MINIMUM_EPOCH_REWARD` is defined in mojos.

## Implementation Notes

- The floor creates a subsidy during tail emission, ensuring validators always receive meaningful compensation.
- The difference between the raw epoch reward (0.64 L2) and the floor (2 L2) represents additional emission beyond the per-block schedule.
- This additional emission is a deliberate design choice to maintain network security incentives indefinitely.
- The floor only becomes relevant after all 4 halvings have occurred (year 12+).
